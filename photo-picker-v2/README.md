# L版えらび v2

L版に印刷する写真を **スマホだけで** 選べるWebアプリです。インストール不要、サーバー不要。写真は端末の外に送信しません。

> v2 は前の版（`photo-picker/`）とは別のURLです。同じブラウザなら、前の版で取り込んだ写真と ♥ をそのまま使えます（取り込み直し不要）。前の版はそのまま残っています。

- スマホで写真を取り込むと、縮小版をスマホの中に保存します。2回目以降は取り込み直さなくてもサクサク見られます。
- ♥ を付けると、その瞬間にスマホへ自動保存されます。途中でやめても、次に開くと前回の続きから表示されます。
- 月ごとの「選んだ枚数 / 全枚数」を常に表示します。
- 拡大表示の「L版枠」で、L版（89×127mm）でフチなし印刷したときに切れる部分を確認できます。
- 最後に、選んだ写真の **リスト** をPCに送ります。PCで `pc.html` を開いて元の写真フォルダを選ぶと、元の写真（フル画質）を月別フォルダにコピーします。

## 使い方

### スマホ
1. ページを開き、共有メニューの「ホーム画面に追加」でアプリとして追加します（データが消えにくくなります）。
2. 「写真を取り込む」で、2025年5月以降の写真を選びます。期間外の写真は自動で除外されます。
3. ♥ で選びます。拡大表示では、左右スワイプで前後に移動、2回タップで ♥ です。
4. 右上の ♥ 枚数 →「リストを送る / 保存」で、LINE やメールなどを使ってPCへ送ります。

### PC（Windows の Chrome / Edge）
1. `pc.html` を開きます。
2. ① リスト → ② `D:\03_年月別バックアップ` → ③ まとめ先 の順に選びます。
3. `L版印刷_日時\2025-05\2025-05_IMG_1234.jpg` のようにコピーされ、`一覧.csv` も作られます。

写真の照合はファイル名と撮影日時（EXIF）で行います。iPhone で名前が変わった写真も、撮影日時から見つけます。

### ☁ スプレッドシートに自動保存（任意）
`sheet-sync.gs` をスプレッドシートの Apps Script に貼り付け、「ウェブアプリ」としてデプロイします（実行ユーザー: 自分 / アクセス: 全員）。表示されたURLを、アプリの「選んだ写真」画面にある「スプレッドシートに自動保存」欄に貼り付けます。
- ♥ を付けたり外したりするたびに、`選んだ写真` シートと `月別` シートが自動で更新されます。PCとスマホなど複数の端末の ♥ は合体して保存されます（他の端末の ♥ を消しません）。
- スマホのデータが消えても、もう一度写真を取り込めば ♥ が自動で戻ります。
- PC の `pc.html` では、リストファイルを送らなくても、同じURLを貼るだけでまとめられます。
- （v3）♥ を付けた・外した記録が `履歴` シートに残ります。アプリの「設定・バックアップ → ♥ の履歴から、前の状態に戻す」で、日時を選んでその時点の ♥ に戻せます。
- （v3）「GigaFile便にアップした写真と照合」に URL を貼ると、♥ の写真と1枚ずつ照らし合わせて、足りない写真・余分なファイルを出します。

### 📱 iPhone の「L判印刷」アルバム
「選んだ写真」画面の「撮影日時のリストをコピー」→ ショートカット「L判アルバム」で、♥ の写真（元の画質）をアルバムにまとめます。作り方はアプリ内の説明と [完成図](shortcut-guide.png) を見てください。旅行先など時差のある写真も、iPhone の時刻に直してリストにします。

### テスト
`tests/` を見てください（実際の写真は使いません）。

### 写真がPCにしか無いとき
`pc.html` の「スマホ用の軽い写真を作る」で、① 写真フォルダ、② 作成先 の順に選ぶと縮小コピーを作ります。撮影日時も埋め込まれ、HEIC にも対応しています。作ったコピーをスマホに移してから取り込んでください。
作成先には新しく作ったフォルダを選んでください。デスクトップやドライブ直下（`D:\`）そのものは、Chrome の制限で選べません。

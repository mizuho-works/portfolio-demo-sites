# L版えらび

`D:\03_年月別バックアップ` の写真（2025年5月以降）をスマホでサクサク見て、L版に印刷する写真を ♥ で選ぶアプリです。
選んだ写真は最後にPCのフォルダへ月別にまとめてコピーできます。

- **写真はPCから外に出ません。** PCで小さなサーバーを起動し、同じWi-Fiのスマホからだけ見られます（URLに合言葉つき）。
- グリッドは縮小画像なので軽く、2回目からはさらに速くなります。
- ♥ はタップした瞬間にPCへ自動保存されます。サーバーを閉じても、また起動すれば続きから選べます（スマホとPCで共通）。
- 月ごとの「選んだ枚数 / 全枚数」をいつでも確認できます。
- 拡大表示で「L版枠」をオンにすると、L版（89×127mm）でフチなし印刷したときに切れる部分が暗く表示されます。

## はじめ方（Windows）

1. **Python を入れる**（初回だけ）
   https://www.python.org/downloads/ からインストールします。最初の画面で「Add python.exe to PATH」にチェックを入れてください。
2. **このフォルダをダウンロード**
   GitHub の「Code → Download ZIP」でダウンロードして展開し、`photo-picker` フォルダを好きな場所に置きます。
3. **`start.bat` をダブルクリック**
   - 初回は必要な部品（Pillow / pillow-heif）が自動で入ります。
   - 「Windows セキュリティの重要な警告」が出たら **プライベート ネットワーク** にチェックを入れて「許可」を押します。
   - PCのブラウザが開き、スマホ用の QR コードが表示されます。
4. **スマホで QR を読み取る**（PCと同じWi-Fiにつないでおく）
   ホーム画面に追加しておくとアプリのように使えます。

黒い画面（サーバー）を閉じるとスマホから見られなくなります。選ぶ作業中は開いたままにしてください。

## 使い方

| 操作 | |
|---|---|
| 上の月ボタン | 月を切り替え。`3/120` は「選んだ枚数 / その月の枚数」 |
| サムネイル右下の ♡ | その場で選ぶ / 外す |
| サムネイルをタップ | 大きく表示。左右スワイプで前後、下スワイプで閉じる |
| 拡大表示で2回タップ / 「印刷する」 | 選ぶ / 外す（PCでは Space キー、←→ で移動） |
| 「L版枠」 | L版で印刷される範囲を表示 |
| 右上の ♥ 枚数 | 月別の集計と「フォルダにまとめる」 |

### フォルダにまとめる

右上の ♥ ボタン → 「フォルダにまとめる」で、写真フォルダと同じ場所（`D:\`）に次のようにコピーされます。元の写真は動かしません。

```
D:\L版印刷_20261120_2130\
  2025-05\2025-05_IMG_1234.jpg
  2025-06\2025-06_IMG_2345.jpg
  一覧.csv
```

iPhone の HEIC 写真は、写真屋さんで使いやすいように JPEG に変換してコピーします（オフにもできます）。

## 設定を変えたいとき

`start.bat` に引数をつけるか、コマンドで起動します。一度指定した値は `data\config.json` に保存され、次回からは不要です。

```bash
python server.py "D:\03_年月別バックアップ" --since 2025-05 --export-to "D:\印刷用" --port 8765
```

- 月の判定はフォルダ名（`2025-05` / `2025年5月` / `202505` / `2025\05` など）→ ファイル名 → 撮影日時（EXIF）の順に見ます。
- 写真を足したときは、まとめ画面の「写真フォルダを読み込み直す」を押します。

## データの置き場所

`photo-picker\data\` に保存されます（GitHub には上がりません）。

- `selections.json` … 選んだ写真の一覧（これが作業の保存データ）
- `position.json` … 最後に見ていた位置
- `config.json` … 設定とスマホ用の合言葉
- `cache\` … 縮小画像（消しても自動で作り直されます）

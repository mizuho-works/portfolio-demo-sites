写真はこのスマホの中だけで処理し、どこにも送信しません。
まとめて選ぶコツ：選択画面で1枚目を押さえたまま指を下へなぞると一気に選べます。1回 1,000枚（1〜2か月分）くらいまでにしてください。何千枚も一度に選ぶと、スマホの準備で固まることがあります。取り込み済みの写真は自動で飛ばすので、何回に分けてもOKです。

写真がPCにしか無いときは → このページをPCのChrome / Edgeで開いて「フォルダごと取り込む」で E:\03_年月別バックアップ を選べば、PCでそのまま選べます。

    ♥ を付けるたびに自分のGoogleスプレッドシートへ自動保存します。スマホのデータが消えても復元でき、PCではスプシからそのまままとめられます。
    状態：未接続

    はじめての設定（3分・最初の1回だけ）
    1. Googleスプレッドシートで 新しいシート を作る（PCがおすすめ）
    2. メニュー 拡張機能 → Apps Script を開き、中身を消して下のコードを貼り付け → 保存
    3. 右上 デプロイ → 新しいデプロイ → 歯車で ウェブアプリ を選ぶ
      「次のユーザーとして実行: 自分」「アクセスできるユーザー: 全員」→ デプロイ
    4. 初回は「アクセスを承認」→ 自分のアカウント →「詳細」→「（無題）に移動」→「許可」
    5. 表示された ウェブアプリのURL をスマホに送り、上の欄に貼って「接続」

    送るのは 年月・ファイル名・撮影日時 だけで、写真そのものは送りません。URLを知っている人はリストを見られるので、URLは人に教えないでください。
